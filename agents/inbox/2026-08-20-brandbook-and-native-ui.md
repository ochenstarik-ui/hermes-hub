# Задание: Внедрение Brandbook, фирменной темы и иконок в Native Windows App Hermes Hub

## Дата поступления
2026-08-20

## Цель
Построить Native Windows UI Hermes Hub на базе утверждённого Brandbook (`Hermes Hub.png`, `Брендбук Hermes Hub.png`):
- Перенос и структурирование brand assets в `assets/branding/`
- Создание multi-resolution `HermesHub.ico` и иконок
- Разработка `docs/brand/BRAND_GUIDELINES.md` и `docs/brand/UI_DESIGN_SYSTEM.md`
- Создание централизованной системы дизайн-токенов (`theme.py`) и библиотеки компонентов
- Полнофункциональный Native Dark-First интерфейс со всеми разделами (Главная, Команда, Аккаунты, Провайдеры, Маршрутизация, Состояние, Журнал, Настройки, О программе)
- Splash Screen, интеграция иконок в Windows, чистый единый процесс без браузера/FastAPI
- Сохранение всей Router/Auth логики и профилей
