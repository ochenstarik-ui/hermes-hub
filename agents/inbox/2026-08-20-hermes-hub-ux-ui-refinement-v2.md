# Задание: Hermes Hub — UX/UI Refinement v2 + Unified Health + Account Workflow

## Дата поступления
2026-08-20

## Область задачи (Scope)
1. Разработка презентационного слоя `ProfileViewModel` и единого сервиса здоровья `UnifiedHealthService`.
2. Устранение противоречивых статусов ("No credentials" + "Здоровый" -> нормализованный `AUTH_REQUIRED`).
3. Агрегатор готовности системы (System Readiness: HEALTHY, LIMITED, DEGRADED, CRITICAL) с понятными пояснениями.
4. Четкое разделение понятий: ACCOUNT (учетная запись), AGENT (логическая роль), ROUTE (маршрут).
5. Разделение понятий "Основной аккаунт Hermes (MAIN)" и "Главный оркестратор (Orchestrator)".
6. Компактная адаптивная сетка Accounts View со слотами "Свободный слот" / "Холодный резерв".
7. Мастер подключения аккаунта (Add Account Wizard: Выбор провайдера -> Авторизация -> Валидация -> Рекомендация Auto Assignment).
8. Детектирование дубликатов аккаунтов.
9. Переработка Health Tracker в структурированную диагностическую таблицу с группировкой по провайдерам и таймштампами проверок.
10. Интерактивные элементы управления в Settings (Session Affinity, failover, auto-return, advanced collapsible).
11. Человекочитаемый Event Log (подключения, квоты, переключения failover).
12. Полное соответствие Brandbook, фоновые воркеры без зависания UI, гарантированный graceful shutdown без зомби-процессов.
13. Автоматизированные тесты и live-валидация.
